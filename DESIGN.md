# Visual direction
Reference layout: the user's Coffee & Cheese site. Palette reference: the actual facade photograph supplied by the user on Facebook (photo ID 1469323468532801). Deep green lettering (#23513c), olive (#52724e), warm limestone cream (#f7f3e7), pale sage (#e9edde), stone (#eeead7) and muted yellow tile accents (#e8ce87). Red and blue are absent from the interface palette. The original facade photograph remains authentic, including the Portuguese flag; food photos retain their natural colours.

Bricolage Grotesque display typography and DM Sans body, self-hosted. Large rounded photographic spreads, spacious split headings, pill controls, single-column menu rows and staggered real interior photographs. The hero leads with type on cream and places a bright photo beneath it. The actual facade appears in the story section with a link to its original post.

# Languages and motion
French is the default on first visit. English and European Portuguese (pt-PT) are complete local translation catalogs, covering navigation, all menu items and descriptions, prices, opening days, calls to action, image descriptions, accessibility labels, page metadata and captions. Proper names and the actual street address retain their original form. The browser remembers an explicit language choice; unavailable local storage falls back safely to French. Language selection preserves the selected specialty, menu category and page position. External booking and menu pages belong to their respective providers.

The header's compact FR / EN / PT button opens a spring-driven anchored menu. Options show their native language names, selected state and keyboard support. Arrow keys, Home, End, Enter and Escape work; selection restores focus to the trigger. Outside clicks dismiss the menu. Text changes have a short opacity transition; reduced motion keeps gentle crossfades. No perpetual animations or per-frame React state updates.

Selecting a specialty turns the photographic spread like a menu page, with an optional slow-motion control. Tabs retain focus and stable category indices across languages. French factual content, prices, contacts, booking and maps are preserved. Google Maps supports a deployment key and a locale parameter; the default embed needs no key. The React/Vite build supports GitHub Pages using its configured base path.
