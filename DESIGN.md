# Visual direction
Reference: the user's Coffee & Cheese site. Bright cream canvas (#f7f3e9), deep restaurant terracotta (#7e3028), clay (#a34935), oatmeal (#eee8d9), peach (#f0e4d4) and warm honey (#f0d59c). No blue in the interface or illustrative food photographs. Bricolage Grotesque display typography and DM Sans body, self-hosted. Large rounded photographic spreads, spacious split headings, pill controls, single-column menu rows, staggered real interior photographs. The hero leads with type on cream and places a large bright photo beneath it. The decorative Portuguese tile motif identifies the cuisine without inventing awards or certifications.

Motion thesis: selecting a specialty lifts and turns the photographic spread like a menu page; the title changes in sync. A slow-motion control lets the visitor slow this moment. Quick spring feedback on controls; no perpetual animation. Hero typography enters once through line masks. Reduced motion replaces spatial movement with crossfades. Tabs preserve focus and remain interruptible. No React state updates per animation frame.

French factual content, menu, contact information, booking and map are preserved. Photos of the venue remain authentic. Generated food photographs remain labeled as illustrative. Google Maps supports an optional deployment key; its default embedded address works without one. The React/Vite build supports a GitHub Pages subdirectory using its configured base path.
